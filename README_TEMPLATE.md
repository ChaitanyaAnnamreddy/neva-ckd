## The Problem

Nearly 9 million people in Karnataka have undetected Chronic Kidney Disease. 90% of CKD cases in India are caught too late — when dialysis costing ₹5–10 lakh per year is the only option. Current screening is hospital-centric and reactive.

## What Neva Does

Neva is a community-centred kidney risk awareness platform. It combines a simple lifestyle questionnaire with an ML-powered risk engine and AI-generated health guidance — all accessible from any smartphone, no lab visit required.

## How It Works

1. **Questionnaire** — 8 questions about age, diabetes, BP, hydration, and lifestyle
2. **ML Risk Scoring** — XGBoost model trained on the UCI CKD dataset (F1: _fill in_)
3. **AI Explanation** — Gemini 1.5 Flash generates personalised plain-language advice

## Setup

```bash
git clone https://github.com/YOUR_USERNAME/neva-ai.git
cd neva-ai

# Create virtual environment (recommended)
python3 -m venv venv
source venv/bin/activate

# Install dependencies
pip install -r requirements.txt

# Set Gemini API key
echo "GEMINI_API_KEY=your_key_here" > .env

# Run
python app.py
```

Open `http://localhost:5000` in your browser.

## Dataset

UCI Chronic Kidney Disease Dataset (CC BY 4.0)
- 400 patients, 25 features, binary classification (CKD / not CKD)
- Citation: Rubini, L., Soundarapandian, P., & Eswaran, P. (2015). UCI Machine Learning Repository. https://doi.org/10.24432/C5G020
